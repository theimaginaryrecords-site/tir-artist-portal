Setup Guide — For TIR Admin
This page is a step-by-step guide for setting up the backend (Firebase + Google Drive) so this dashboard works fully. Share this with your developer or follow it yourself.
Step 1 — Create Firebase Project (Free)
  1. Go to console.firebase.google.com → "Add project" → name it tir-artist-portal
  2. Enable Authentication → Sign-in method → Email/Password → Enable
  3. Enable Firestore Database → Start in test mode (secure later)
  4. Go to Project Settings → Your apps → Add Web app → Copy the config object
  5. Replace YOUR_API_KEY etc. in the <script> at the top of this HTML file with your real config
Step 2 — Set Up Google Drive Folder (Free)
  1. Create a Google Drive folder called "TIR Submissions"
  2. Inside it, create sub-folders: Audio Files and Artwork
  3. Right-click the folder → Share → Change to "Anyone with the link can edit"
  4. Copy the folder link and paste it below as your upload destination
Step 3 — Firestore Security Rules
  1. In Firebase Console → Firestore → Rules → replace with these rules to secure your data:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth.uid == userId;
    }
    match /releases/{releaseId} {
      allow read, write: if request.auth != null
        && request.auth.uid == resource.data.userId;
      allow create: if request.auth != null;
    }
  }
}
Deployment — Host Free on GitHub Pages or Vercel
  1. Save this HTML file as index.html
  2. Push to a GitHub repo (e.g. tir-artist-portal)
  3. Go to repo Settings → Pages → Source: main branch → Save
  4. Your portal will be live at yourusername.github.io/tir-artist-portal
